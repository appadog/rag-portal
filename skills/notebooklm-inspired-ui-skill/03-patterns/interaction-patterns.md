# Interaction Patterns

## Panel Toggle

- Header의 일관된 위치
- Tooltip
- 상태 저장
- rail에서 다시 열기
- 닫힌 후 합리적 focus 이동

## Search and Filter

- 검색 즉시 적용
- 고급 필터 Popover
- 활성 필터 수
- Clear all
- 검색 중 selected 유지

## Inline Rename

- Enter 저장
- Escape 취소
- blur 정책 정의
- 실패 시 inline 오류

## Configure

고급 설정은 Dialog 또는 Drawer.

- 응답 스타일
- 길이
- 역할
- 출력 언어
- 생성 옵션

## Jump to Top

긴 콘텐츠에서 아래로 이동한 경우만 floating pill로 표시한다.

## Toast

적합:

- 저장·복사 완료
- 삭제 Undo
- 백그라운드 작업 완료

부적합:

- 폼 오류
- 권한 설명
- 데이터 손실 경고

## Confirmation

```text
“시장 분석 보고서”를 삭제할까요?

삭제하면 복구할 수 없습니다.
```

## Notifications

앱 내 상태가 우선이고 브라우저 알림은 보조다.
