# Empty, Loading, Error

## Empty

1. 무엇이 비어 있는가
2. 왜 필요한가
3. 다음 행동

```text
아직 결과물이 없습니다.

현재 데이터를 기반으로 보고서나 요약을 생성할 수 있습니다.

[결과 만들기]
```

## Skeleton

사용:

- 최초 화면
- 구조가 알려진 목록
- 상세 최초 로딩

금지:

- 생성형 텍스트
- 업로드 progress
- 버튼 처리
- 기존 콘텐츠 재검증

## Progress

```text
파일 업로드 중 72%
```

```text
데이터를 분석하고 있습니다.
```

알 수 없는 진행률을 임의로 증가시키지 않는다.

## Inline Error

```text
이 항목을 동기화하지 못했습니다.
[다시 시도]
```

## Panel Error

```text
결과 목록을 불러오지 못했습니다.

네트워크 연결을 확인한 뒤 다시 시도해 주세요.

[다시 시도]
```

## Permission

```text
이 결과물을 볼 권한이 없습니다.

소유자에게 보기 권한을 요청해 주세요.
```

## Offline

- 캐시 콘텐츠 유지
- 오프라인 배지
- 저장 대기
- 재연결 정책
