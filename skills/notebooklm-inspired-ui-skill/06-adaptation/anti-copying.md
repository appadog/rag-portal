# Anti-Copying Rules

## 복제하지 않는 요소

- Google 또는 NotebookLM 로고
- 고유 이모지 스타일
- 고유 문구
- 정확한 색상·아이콘 조합
- 고유 결과물 이름
- 공식 스크린샷
- 고유 애니메이션

## 재사용 가능한 원리

- 역할 기반 3영역
- 패널 가변 폭
- Select와 Open 분리
- 중앙 작업 우선
- Output object 관리
- 인라인 검증
- 차분한 surface
- 고정 Composer
- 점진적 정보 밀도

## 반드시 변경할 요소

- Primary color
- Typography
- Icon vocabulary
- Radius scale
- Empty State 이미지
- 도메인 용어
- Output type
- Header 구조

## 우선순위

NotebookLM과 비슷해 보이는 것보다 사용자 도메인·기존 제품 일관성·작업 효율·접근성·검증 가능성이 중요하다.
