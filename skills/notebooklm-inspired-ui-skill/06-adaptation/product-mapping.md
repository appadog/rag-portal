# Product Mapping

## 기본 변환

```text
Sources → Context
Chat → Core Work
Studio → Output
Viewer → Evidence/Detail
```

## AI Workflow Builder

| 역할 | 적용 |
|---|---|
| Context | 노드 라이브러리, 서비스, 자산 |
| Work | Flow Canvas |
| Output | 실행 결과, 로그, 테스트 |
| Detail | Node Inspector |

```text
Node Library | Flow Canvas | Inspector
```

실행 결과는 Output Drawer 또는 Bottom Panel로 확장할 수 있다.

## Prompt Management

| 역할 | 적용 |
|---|---|
| Context | 템플릿, 버전, 변수 |
| Work | Prompt Editor / Playground |
| Output | 실행 기록, 평가 |
| Detail | 버전 비교 |

## Knowledge System

| 역할 | 적용 |
|---|---|
| Context | 문서 목록과 선택 |
| Work | Chunk / Search Test |
| Output | 검색 결과, 평가 |
| Detail | 원문 Viewer |

Citation 패턴을 직접 적용하기 좋은 도메인이다.

## Admin

| 역할 | 적용 |
|---|---|
| Context | 메뉴와 필터 |
| Work | 목록 또는 상세 |
| Output | Inspector / 변경 기록 |
| Detail | Drawer |

Admin에서는 2패널이 더 적합할 수 있다.

## Analytics

| 역할 | 적용 |
|---|---|
| Context | 데이터셋, 기간, segment |
| Work | 차트와 분석 |
| Output | 저장 리포트 |
| Detail | 데이터 포인트, 쿼리 |

## Non-AI Editor

AI 규칙을 제거하고 다음만 유지한다.

- Context / Work / Output
- 패널 전환
- 읽기 폭
- 결과물 객체
- 상태와 접근성

## 적용하지 않을 경우

- 단일 폼
- 랜딩 페이지
- 마케팅 사이트
- 멀티패널이 작업을 분산시키는 모바일 중심 제품
