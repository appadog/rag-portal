# Sprint 03 — 설명 가능한 임베딩 모델 후보 선택

## Objective

질문 응답만으로 임베딩 모델 하나를 자동 확정하지 않고, 사용자가 추천 후보를 비교해 지식 공간 단위의 모델 하나를 선택하게 한다.

## Delivered

- 모델 추천 API가 세 후보를 순위·추천 여부·선택 이유·확인할 점과 함께 반환한다.
  - BGE-M3: 균형형 다국어 검색
  - Qwen3-Embedding-0.6B: 자체 운영 우선
  - EmbeddingGemma-300M: 경량 운영형
- 생성 화면은 질문 → 후보 비교/선택 → 이름/문서 업로드 흐름으로 바뀌었다.
- 선택 모델은 `RagInstance.embedding_model`에 영속되며, 사용자는 추천이 아닌 후보도 선택할 수 있다.
- 로컬 미리보기는 아직 lexical retrieval이라는 한계를 선택 화면에 명시한다. 모델별 실측 품질 주장은 실제 임베딩 연결과 벤치마크 이후에만 제공한다.

## Acceptance checks

- 자체 운영 요구 시 Qwen3-Embedding-0.6B가 1순위 후보로 보인다.
- 후보는 모두 키보드로 선택할 수 있고, 추천 후보가 기본 선택된다.
- 사용자가 BGE-M3 등 다른 후보를 선택하면 그 값이 인스턴스에 저장된다.
- mock fallback에서도 동일한 후보 선택 흐름을 유지한다.

## Next boundary

선택한 모델을 실제로 실행하려면 provider adapter, 토큰·비용 정책, 재시도 큐, 그리고 우리 문서 기준의 benchmark run을 연결해야 한다. 이 작업 전에는 모델별 검색 품질 차이를 UI나 API가 단정하지 않는다.
